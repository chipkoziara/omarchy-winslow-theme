# Winslow - Theme for Omarchy

A dark, calm theme for [Omarchy](https://omarchy.org/), inspired by the seascapes of American painter [Winslow Homer](https://en.wikipedia.org/wiki/Winslow_Homer) (1836–1910).

The palette is generated by [Aether](https://aether.dev/) from the Homer artworks shipped in `backgrounds/` — muted, earthy tones pulled from the ocean, sand, and sky of paintings like *Right and Left* (1909) and *Summer Squall* (1904).

## Installation

### Method 1: Launcher

1. Copy the git URL of this repository
2. Press `SUPER + ALT + SPACE`
3. Click **Install > Style > Theme**
4. Paste the link

### Method 2: CLI

```bash
omarchy theme install https://github.com/<you>/winslow-omarchy-theme.git
```

### Method 3: Local

Symlink or copy this directory into `~/.config/omarchy/themes/`:

```bash
ln -s "$PWD" ~/.config/omarchy/themes/winslow
```

Then apply it:

```bash
omarchy theme set Winslow
```
